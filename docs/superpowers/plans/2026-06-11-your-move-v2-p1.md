# Your Move v2 — P1: Drop-Cost Netting + Side/Margin Filter

> REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]`.

**Goal:** Make every "Your Move" a believable, drop-aware swap. Score each candidate net of the player you'd drop (or sit), never drop a keeper, and only "flip" categories the move's side can actually swing by a meaningful margin. No new data.

**Architecture:** Generators become thin — each emits a `MoveCandidate {kind, player, side, addDelta, detail}` with no scoring. A central `buildMoves()` pairs the drop/sit, computes the net delta, derives the honestly-flipped categories (side + per-cat margin), scores the net win-prob lift, and suppresses keeper-drops / sub-floor moves. `rankMoves` ranks the result.

**Spec:** `docs/superpowers/specs/2026-06-11-your-move-v2-horizon-and-drop-cost.md` (P1).

**Constraint:** LOCAL ONLY on `redesign/my-team-first`.

## Task 2: pairDrop + buildMoves (the netting core)

**Files:** create `pairDrop.ts`, `buildMoves.ts`; tests.

- [ ] `pairDrop.ts`:
```ts
export interface RosterSlotPlayer { playerKey: string; name: string; side: Side; roleValue: number; started: boolean; stats: Record<string, number> }
const KEEPER_FLOOR = 50 // roleValue >= this is a keeper; not droppable/sittable for a swap
// add/stream -> weakest droppable same-side ROSTER player; startSit -> weakest STARTED same-side player (the one you'd sit)
export function pickCounterparty(roster, side, kind): RosterSlotPlayer | null
```
Returns the lowest-roleValue eligible same-side player below KEEPER_FLOOR, else null (suppress — don't churn a strong roster).
- [ ] `buildMoves.ts`: `buildMoves(candidates: MoveCandidate[], roster: RosterSlotPlayer[], flippableCatIds, cats, ctx, fraction): CandidateAction[]`. For each candidate: pick counterparty; if none -> drop the move. `counterpartyProj = projectRemainingWeek(counterparty.stats, null, cats, ctx.days, fraction)`; `netDelta = addDelta - counterpartyProj` (per cat). `categories = helpedCats(netDelta, flippable, cats, side, ctx)`; if empty -> drop. `winProbLift = scoreCandidate(netDelta, ctx)`. Build `CandidateAction` with `counterparty {key,name}`, `categories`, `winProbLift`, `rationale = detail`.
- [ ] Tests: a swap that strictly improves -> lift > 0 and counterparty set; dropping a keeper-only roster -> no candidates; net delta nets the counterparty's projection; startSit pairs the weakest started same-side player.
